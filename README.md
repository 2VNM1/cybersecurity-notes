# Cybersecurity Notes

Personal learning notes for a transition from IT support to application security.

## Purpose

This repository is a living structure for organised, responsible learning. It is not a catalogue of findings, targets, or exploits.

## Boundaries

- Work only in authorised labs, CTFs, and explicitly scoped programs.
- Never store credentials, tokens, personal data, private reports, or sensitive target information.
- Do not publish exploit code or unverified technical claims.
- Share only material that is safe, lawful, and authorised to disclose.

## Structure

- [`notes/`](notes/) — concept notes and learning summaries
- [`labs/`](labs/) — authorised lab and CTF learning summaries
- [`resources/`](resources/) — curated learning resources
- [`templates/`](templates/) — generic learning templates
- [`writeups/`](writeups/) — authorised, high-level reflections

## Status

Each folder currently contains a short placeholder README. Content will be added only when it is accurate, authorised, and useful.
